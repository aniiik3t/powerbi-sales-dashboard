# Sales Dashboard — Power BI

## Project Overview
An interactive Sales Dashboard built using Microsoft Power BI to analyze sales performance and identify key business trends.

## Key Features
- KPI Cards for sales performance monitoring
- Month-wise and year-wise sales analysis
- Product-level sales analysis
- Interactive slicers and filters
- Data visualization for business insights

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## Project File
`Sales Dashboard.pbix`

## Objective
To practice data analysis, dashboard development, and interactive reporting using Power BI.
