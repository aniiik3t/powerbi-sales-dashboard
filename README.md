# Sales Dashboard — Power BI

## Project Overview
An interactive Sales Dashboard developed using Microsoft Power BI to analyze sales performance, monitor key metrics, and identify business trends.

## Project Objectives
- Analyze sales performance across different periods.
- Monitor key sales KPIs.
- Understand product and customer sales trends.
- Practice interactive dashboard development and data visualization.

## Key Features
- KPI Cards for sales performance monitoring
- Month-wise and year-wise sales analysis
- Product-level sales analysis
- Customer-level sales analysis
- Interactive slicers and filters
- Visual representation of sales trends and insights
